# Memory and ideas

## Preferences

Open **Memory & preferences** to edit the agent's name and the preferences you want new tasks to use. Write durable instructions such as formatting or workflow preferences. Keep passwords and API keys out of this field.

## Dreaming notes

The **Dreaming** area reviews prior user messages for possible workflow lessons or preferences. It runs once per day after the configured local time when the harness is online and idle; the default is 03:00 in the server's time zone. It does not retrain model weights.

The app keeps a journal and shows candidate notes for review. You can edit, pause, or forget a note. Workflow lessons may become active automatically after evidence checks; preferences and conflicts require review. Forgotten notes stop appearing in future retrieval, but forgetting a note does not delete the original conversation or past model session logs.

Work supplies a small set of relevant active notes to new tasks. For exact figures, files and deterministic tools remain the source of record.

## Ideas

Open **Ideas** and choose **Suggest some ideas** or **Refresh ideas**. Seek proposes possible tasks from what you previously asked and what you chose to remember. Read the title and reason, then choose **Do it** only for an idea you want to start. You can also adapt an idea in a new conversation.

The workspace can be shared by the owner and a partner login. Shared members see the same tasks, files, memory, and ideas, so review preferences with that in mind.
